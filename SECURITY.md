# Security Policy

The latest code on the `main` branch is the primary target for security fixes.
Published releases may receive fixes when practical.

Do not post exploit details, private documents, or personal data in a public
issue. Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/younsabood/hdoc-encoder/security/advisories/new).
Include the affected revision, impact, and a minimal reproduction when safe.

If private reporting is unavailable, contact the maintainer through the
[GitHub profile](https://github.com/younsabood). Please allow time to investigate
and prepare a fix before public disclosure.
