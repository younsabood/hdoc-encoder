# Code of Conduct

We want participation in HyperDoc Encoder to be respectful, constructive, and
welcoming to people with different backgrounds and experience levels. These
expectations apply to issues, pull requests, code reviews, and project forums.

## Expected behavior

- Be kind and direct when discussing ideas and code.
- Give actionable feedback and accept good-faith corrections.
- Respect privacy and personal boundaries.

Harassment, discrimination, threats, personal attacks, and publishing private
information are not acceptable. Maintainers may edit or remove content and may
restrict participation when these expectations are violated. For a conduct
concern, contact the maintainer through the [GitHub profile](https://github.com/younsabood).

For security issues, use the private reporting process in [SECURITY.md](SECURITY.md).
